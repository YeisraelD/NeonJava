# Staking Client (Java)

This is a Java client application that interacts with the `StakingPool` smart contract.

## Features
- Connects to a local Anvil node (port 8545).
- Fetches the latest block number.
- Checks the ETH balance of a hardcoded test account.

## Setup
1. Run the Anvil node from the `smartContract` directory (`anvil`).
2. Run this Java application using your preferred IDE or Maven.

Note: This project uses `web3j` for Ethereum interaction.
