# Ethereum Staking Pool (DeFi Style)

A simple smart contract for staking ETH and earning rewards (conceptual).

## Features
- **Stake ETH**: Users can deposit ETH into the pool.
- **Unstake ETH**: Users can withdraw their ETH.
- **Reentrancy Protection**: Secured with a reentrancy guard.

## Smart Contracts
- `StakingPool.sol`: Core staking logic.
- `Counter.sol`: (Boilerplate) Counter example.

## Usage

### Build
```shell
forge build
```

### Test
```shell
forge test
```

### Local Node (Anvil)
```shell
anvil
```
